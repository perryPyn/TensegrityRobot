# TensegrityRobot
## 📖 À propos du projet
L’objectif de ce projet est de créer un bras robotique poly-articulé basé sur le principe de tenségrité en faisant le design 3D et en le contrôlant avec servomoteurs. Pour commencer nous avons donc réalisé un prototype d'articulation de type coude.
## 🛠️ Matériel requis
* 1x Arduino Mega
* 4x Servomoteurs FEETECH STS3215
* Alimentation externe : Adaptateur secteur universel AC réglable 12W (reglé sur 7.5 V)
